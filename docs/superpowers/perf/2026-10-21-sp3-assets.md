"RGBA MB" is width × height × 4 bytes, the decoded GPU footprint (MiB). A game holds one board (6.2 MB instead of 19.0), the table, and both atlases.

Notes:
- **Checkers:** the three sets' checker PNGs are byte-identical, so one atlas serves every set. The legacy bundle ships the set three times (1.59 MB).
- **Atlases:** sprites are cropped to alpha > 0 and packed with 4 px transparent padding. Checker discs are 192 px (source 222), die faces native (about 135), cube faces 192 (source 205).
- **Legacy assets** stay until legacy deletion, because the online screen still uses them.
